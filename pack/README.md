# studio-sassfully gitflow pack

This pack installs the primary-checkout `reference-transaction` guard. The
tracked `.claude/hooks/block-bare-checkout.sh` and `.claude/settings.json`
provide the companion agent-level PreToolUse guard. Copy
`.kitsoki.local.yaml.example` to `.kitsoki.local.yaml` to enable Kitsoki's
launch policy with machine-local sibling roots.
